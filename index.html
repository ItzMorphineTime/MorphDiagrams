MorphDiagrams

Start a system diagram

Pick a device from the palette and click on the canvas, then draw connections port to port with the connector tool.

Press E for a generic device, L to connect, ? for all shortcuts — or insert a template.

Shortcuts & tips

Tools

V
Select
L / P
Connector / polyline connector
R C D H T
Rectangle, circle, diamond, hexagon, text
E
Generic device
Esc
Cancel / deselect / back to select

Editing

Double-click / F2
Edit label or text in place
Ctrl+Z / Ctrl+Y
Undo / redo
Ctrl+C V X D
Copy, paste, cut, duplicate (keeps connections)
Ctrl+A
Select all
Ctrl+G / Ctrl+Shift+G
Group / ungroup
Del
Delete selection (connectors of deleted shapes go too)
Arrows / Shift+Arrows
Nudge by 1 px / one grid step
[ ] Shift+[ ]
Layer backward / forward / to back / to front

Connections

Drag port → port
Hollow dots are free ports, filled ones are used. Only compatible ports highlight.
Right-click a link
Add a waypoint, remove one, straighten, reverse direction, edit label
Alt+click waypoint
Remove that waypoint
Drag waypoint
Reshape a polyline; orange handles reshape bezier curves
Right-click a device
Trace downstream (what it feeds) or upstream (what feeds it); everything else fades
F
Filter view: highlight signal types (video, SDI, network, power, …) or device types
